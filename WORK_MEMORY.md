# Rahul Jalan — Work Memory

> Public-safe, evidence-backed snapshot of products, projects, responsibilities, and technical growth. Last updated: 15 August 2026.

## Why this file exists

This is the durable version of “what have I worked on?” It complements the chronological notes in the main README with a project-oriented view that is easier to use for portfolio writing, resumes, LinkedIn updates, interviews, and future planning.

The snapshot was rebuilt from GitHub repository metadata, current READMEs and manifests, commit histories, and changed-file patterns. The audit covered 325 accessible repositories (178 owned and 147 collaborator or organization repositories) and read 34,270 repository commit records across all refs.

Because this repository is public:

- Private repositories are summarized as products or project families instead of being reproduced verbatim.
- Secrets, credentials, infrastructure addresses, customer data, and internal-only operating details are intentionally excluded.
- Access to a team repository is not presented as authorship. Entries emphasize work supported by Rahul-linked commits, existing public records, or clearly labeled team context.
- Repository dates are evidence windows, not necessarily employment dates or product launch dates.

## How to maintain this file

When updating this memory:

1. Add or revise a project only after checking its current README, manifests, and recent commits.
2. Describe the product problem and delivered responsibility before listing technology.
3. Separate personal contribution from team context.
4. Treat user/revenue/performance figures as dated milestones, not permanent facts.
5. Avoid publishing private repository names, credentials, IPs, customer data, or confidential operating detail.
6. Avoid presenting research software as scientific or medical validation.
7. Move projects between current, recent, and historical sections as activity changes.
8. Keep LinkedIn and resume wording shorter than this source document; this file is the memory, not the final profile copy.
